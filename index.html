Git na Prática: Comandos e Conflitos

Resumo de comandos principais

  • git init — iniciar repositório
  • git status — verificar estado do repositório
  • git add . — adicionar tudo à staging
  • git commit -m "mensagem" — salvar alteração
  • git push — enviar alterações

GIT/GITHUB

  • - Criação de features:
  • • Crie a branch: git checkout -b feature/nome
  • • Exemplo: feature/01-inicio

  • - Rebase com main:
  • • Atualize: git fetch origin
  • • Rebase: git rebase origin/main

  • - Guardar alterações com git stash:
  • • Salvar: git stash
  • • Com mensagem: git stash save "mensagem"
  • • Recuperar: git stash apply ou git stash pop

  • - Reset e Revert:
  • • Revert (mantém histórico): git revert <hash>
  • • Reset (apaga histórico local): git reset --hard <hash>

  • - Atualizar e enviar pro GitHub:
  • • Puxar do remoto: git pull
  • • Enviar para remoto: git push
